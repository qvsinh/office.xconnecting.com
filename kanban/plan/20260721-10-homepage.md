# 10 — Public Homepage / Landing

**Goal:** Replace the default CodeIgniter welcome page. Authenticated users hitting
`/` are sent to their dashboard; guests see a branded landing with a Login CTA.

## Files
- Modify `app/Controllers/Home.php`.
- Create `app/Views/home/landing.php` (standalone page — NOT the app shell, since
  guests aren't logged in; simple self-contained Tailwind page using /css/app.css).
- Tests: `tests/feature/Web/HomeTest.php`.

## Behaviour (Home::index)
- If `is_authenticated()`: redirect to `is_admin() ? '/admin/dashboard' : '/dashboard'`.
- Else: render `home/landing` (respect the basic-auth gate, which already runs
  globally before this).

## Landing view (mobile-first, self-contained)
- Uses the admin-editable `site_name()` for the brand.
- Hero: brand name, one-line description ("Your company's internal workspace —
  projects, tasks, files, and an API for your AI agents."), a primary "Log in"
  button → `/login`, dark-mode aware, Outfit font, matches the app's visual style.
- A compact feature grid (Workspaces & Projects, Kanban Tasks, File Sharing,
  Groups & Permissions, REST API for AI agents, Dashboards) — static cards.
- Footer with the site name + year. All dynamic output `esc()`-escaped.

## Tests
- Guest `GET /` → 200 and body contains the site name / "Log in".
- Authenticated client → redirect to `/dashboard`; admin → `/admin/dashboard`.
