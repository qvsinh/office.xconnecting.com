# 09 — In-app Docs & API Connection Guide

**Goal:** In-app documentation: how to use the hub, and a REST API reference /
connection guide for wiring an AI agent to a project with an API key. Tested
(routes render, linked from the shell + API-keys page).

**Depends on:** 06, 07 (so examples match reality).

## Files
- Create `app/Controllers/Docs.php` (authFilter — internal docs).
- Views: `app/Views/docs/index.php` (overview + sidebar), `docs/api.php`
  (REST reference + connect guide), `docs/getting_started.php`.
- Modify `Routes.php` (authFilter group), `layouts/app.php` (top-level "Docs"
  link in both zones).
- Tests: `tests/feature/Web/DocsTest.php`.

## Routes (authFilter group)
```
$routes->get('docs', 'Docs::index');
$routes->get('docs/getting-started', 'Docs::gettingStarted');
$routes->get('docs/api', 'Docs::api');
```

## Content (static, English, escaped where dynamic)
- **Getting started:** create a workspace → invite members / add a group →
  create a project → add tasks on the board → upload files.
- **API guide (`docs/api`):**
  - How to create an API key (`/account/api-keys`), scopes, expiry, security note
    (treat like a password; only shown once).
  - Base URL (derive from `base_url('api/v1')`), auth header
    `Authorization: Bearer <token>`.
  - Endpoint table (from feature 07) with method, path, params, sample response.
  - Copy-paste examples: `curl`, and a short Python snippet, and a plain-English
    "prompt" block showing how to tell an AI agent to use the key + base URL to
    list projects and create tasks.
  - Render code blocks in a styled `<pre>` with a copy button (`window.copyText`).

## UI (TailAdmin, mobile-first)
- Docs layout: left sticky nav (collapses to a top dropdown on mobile), right
  content column with readable prose (`max-w-3xl`, prose-like spacing via Tailwind).
- Code blocks: dark rounded panel, horizontal scroll on overflow, copy button.

## Tests
- `/docs`, `/docs/getting-started`, `/docs/api` render 200 for an authed user;
  guest → /login. `docs/api` output contains the base URL and the Bearer header.
