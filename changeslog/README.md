# changeslog

Raw prompts given to the AI agent while building this rebuild, kept verbatim for later review.

- One file per prompt (or per session), named `YYYY-MM-DD-NN-slug.md`.
- Store the prompt **as written** — no cleanup, original language kept. This is a record of
  intent, not documentation.
- Optional: a short note on the decisions and what the agent did in response.

This is a log, not a spec. The living project docs are `CLAUDE.md` and `.claude/`.
